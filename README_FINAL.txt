AETHERIUM ACADEMY — FINAL WEBSITE PACKAGE

This folder is the web package. Printed documents are intentionally NOT included.

FILES TO KEEP TOGETHER
- index.html
- assets/final/  (all images used or reserved by the final build)

GITHUB PAGES — FINAL SETUP
1. Open your GitHub repository: Aetherium.
2. Make sure you are on the main branch.
3. Upload index.html AND the complete assets folder to the ROOT of the repository.
   The final repository must look like:

   Aetherium/
   ├── index.html
   └── assets/
       └── final/
           └── ...images...

4. If old files already exist, replace index.html and replace/merge assets/final with this version.
5. Do NOT rename index.html.
6. Do NOT rename or move the files inside assets/final after upload.
7. Commit the upload.
8. In GitHub: Settings → Pages → Build and deployment → Deploy from a branch.
9. Select branch: main, folder: /(root), then Save.
10. Wait a few minutes and open:
    https://florinedespiegeleer.github.io/Aetherium/

FINAL CHECK BEFORE GAME NIGHT
- Open the GitHub Pages URL on the projector laptop.
- Hard refresh once (Ctrl+F5 on Windows / Cmd+Shift+R on Mac).
- Test Settings and Dossier.
- Open Academy Map from the dossier.
- Test all 3 onboarding QR codes using 3 phones.
- Confirm each phone loads over mobile data/Wi-Fi and reaches its ready code.
- Test one later private QR phase if available.
- Test AI narration. If it falls back to robotic browser speech, use the replay button once; internet is required for hosted AI audio.
- Use Spotify separately for background music; in-game synthetic background music is intentionally disabled.
- Set projector brightness before starting.

IMPORTANT
The QR system needs the GitHub Pages URL. Do not run game night from a local file:// copy if players need to scan QR codes from other devices.
