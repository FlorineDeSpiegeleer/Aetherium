# Aetherium Academy — De Nacht van de Holle Ster

Volledige projector + phone + print versie voor 3 spelers. 

## Installeren op GitHub Pages
1. Maak één nieuwe GitHub repository.
2. Upload alle bestanden/mappen uit deze map naar de root.
3. Settings → Pages → Deploy from a branch → `main` → `/root`.
4. Wacht tot GitHub de publieke Pages-link toont.
5. Open die URL op de laptop die aan de beamer hangt.

## Voor jullie beginnen
- Print `print/Aetherium_Printpakket.pdf`.
- Sorteer de pagina's A, B, C, D en E zonder ze inhoudelijk te bestuderen.
- Zorg dat Florine, Margot en Selena elk een telefoon met internet hebben.
- Zet het beamerbrowservenster op fullscreen.
- Zet geluid aan als je browserstem wilt gebruiken; anders verschijnen alle dialogen automatisch als tekstballonnen.
- Dialogen gaan vanzelf verder. Pauze en 'volgende zin' blijven beschikbaar.
- QR-codes leiden naar persoonlijke pagina's binnen dezelfde GitHub-site.
- Persoonlijke informatie hoeft niet gedeeld te worden.
- De site bewaart keuzes lokaal op het toestel.

## Spoilerwaarschuwing
Open `assets/story.dat` niet. De game zelf onthult de oplossing pas op het juiste moment.


## Finale afwerking
- `Sfeer` schakelt originele, subtiele achtergrondambience in.
- Belangrijke overgangen hebben een zachte klank en korte bliksemflits.
- `Dossier` opent op elk moment het actuele bewijsbord.
- Dialogen verschijnen automatisch; belangrijke langere zinnen krijgen extra leestijd.
- De knoppen `Pauze` en `Volgende zin` blijven beschikbaar als iemand iets mist.
- Geen externe muziekstream nodig: de geluidsbestanden zitten lokaal in de repository.


## Laatste verhaalupdate
De verborgen finale is opnieuw gebalanceerd zodat vroege vermoedens niet automatisch de uiteindelijke oplossing verraden.

## Gameplay-update v3
- Vijf kernpuzzels blijven behouden, maar puzzel 1, 2 en 4 zijn gelaagder.
- Minstens drie NPC-interviews zijn nu echte spelerkeuzes.
- Meerdere personages hebben aantoonbare nevengeheimen die niet automatisch met de moord te maken hebben.
- Persoonlijke keuzes en split-momenten leveren verschillende bewijsfragmenten op.
- Florine, Margot en Selena hebben nu meer details uit hun inschrijvingsprofielen in hun alternate-universe personages.
- De finale vraagt expliciet om ook tegenbewijs voor de eigen topverdachten te overwegen.
